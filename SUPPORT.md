# Getting help

- **Questions and ideas:** [Discussions](https://github.com/alliecatowo/jupyterlite-web-mcp/discussions) (Q&A and Ideas categories).
- **Bugs:** [open an issue](https://github.com/alliecatowo/jupyterlite-web-mcp/issues/new/choose) with your browser, JupyterLab/JupyterLite version and the agent or client you used.
- **Security problems:** please don't open a public issue; see [`SECURITY.md`](SECURITY.md).
- **Install problems:** start with [`docs/install.md`](docs/install.md).

This is a small project maintained in spare time, so replies can take a few days.
